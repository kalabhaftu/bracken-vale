# Security policy

Please report security vulnerabilities privately. Use **Security → Report a vulnerability** on the GitHub repository when private vulnerability reporting is available. If that option is unavailable, contact [@kalabhaftu](https://github.com/kalabhaftu) privately. Do not post a vulnerability, exploit details, credentials, or sensitive logs in a public issue.

Include the affected version, Windows version and architecture, impact, and concise reproduction steps. Redact usernames, file paths, tokens, and other private data. The maintainer will acknowledge the report and coordinate a fix and disclosure; response timing depends on availability and severity.

The latest stable release is the supported release line. Until a stable release exists, report issues against the current development build.
